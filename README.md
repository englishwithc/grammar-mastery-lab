# Grammar Mastery Lab

Free, interactive English grammar lessons that you can show on screen in your classroom or in an online lesson.

[![Open the Grammar Mastery Lab](https://img.shields.io/badge/CLICK%20HERE-Open%20the%20Grammar%20Lab-2ea44f?style=for-the-badge)](https://englishwithc.github.io/grammar-mastery-lab/)

Click the green button above to open the lesson menu. Then choose a topic.

## What is this?

Grammar Mastery Lab is a collection of short, visual lessons for English teachers. Each lesson explains one grammar point with animations, diagrams, and step-by-step examples. You can share your screen and go through them with your students, whether they are in the room or joining online.

No login, no software, and no downloads are needed. It works in any modern web browser on a computer, tablet, or interactive whiteboard.

## How to use it in your lesson

1. Click the green **Open the Grammar Mastery Lab** button at the top of this page.
2. Choose a topic from the menu.
3. Share your screen in your video call or projector setup.
4. Click through the lesson with your students.
5. Refresh the page or return to the menu to choose another topic.

## Tips for teachers

- Use full screen mode (usually the F11 key on Windows, or the green button on a Mac) for a cleaner view.
- Lessons work offline once they have loaded, but an internet connection is needed the first time.
- If a lesson looks wrong or does not load, try refreshing the page once. If it still does not work, see the section below.

## For the repository owner

To add a new lesson:

1. Create a new folder in this repository named after the topic, using lowercase letters and hyphens (for example, `present-continuous`).
2. Add an `index.html` file to that folder. This is the lesson page.
3. Add the lesson to the menu on the main `index.html` file, in the `topics` list.
4. Add a row to the table in this README with the new link.

Lesson links follow this pattern:
`https://englishwithc.github.io/grammar-mastery-lab/[folder-name]/`
