Regular Verbs vs. TO BE Questions

🟢 Regular Verbs (like, play, work)

Do/Does + subject + base verb + …?

Needs the "do/does" helper!

🟠 TO BE (am, is, are)

Am/Is/Are + subject + …?

No "do/does", no base verb!

How to Choose: Quick Decision Guide

Question 1: Is there a main action verb (like, play, study, watch)?
✅ YES → Use do/does + subject + base verb.
❌ NO → Go to question 2.
Question 2: Does the sentence describe being, feeling, or a location (happy, a doctor, at home, from Spain)?
✅ YES → Use am/is/are + subject + complement.
💡 "To be" needs no helper verb — it moves to the front by itself!
